# 16Projects Cybersecurity Resources
A curated list of cybersecurity related courses, tools, and tutorials shared by the community

## Courses
  - [SOC Radar University](https://academy.socradar.io/start) : CTI related courses
  - [Red Team Leader](https://courses.redteamleaders.com/catalog) : Blue, Red and Purple Team free courses
  - [UC Malware Analysis](https://class.malware.re/) : University of Cincinnati's malware analysis course
  - [Azeria Labs](https://azeria-labs.com/writing-arm-assembly-part-1/) : ARM training and labs
  - [OpenSecurityTraining2](https://p.ost2.fyi/) : Free cybersecurity training

## Tools
  - [Tooldump](https://tooldump.eu/tools) : Open sources tools for Cyber Defense, AI, Automation and many more
  - [SANS Faculty Free Tools](https://www.sans.org/img/free-faculty-tools.pdf?msc=sans-free-lp) : A list of SANS open source tools
  - [Matkap](https://cti.monster/blog/2025/02/22/matkap.html) : Tool for hunting Telegram Bots
  - [Consensus-OSINT](https://github.com/OSINT-Experts-Society/Consensus-OSINT) : An OSINT lookup tool
  - [Vecert Global Monitoring](https://analyzer.vecert.io/) : Global threat intel overview platform
  - [OSIRIS AI](https://osirisai.live/) : Open source global intelligence
  - [Zero Day Clock](https://zerodayclock.com/) : Public scoreboard for vulnerability management and exploitation
  - [Wazuh MCP Server](https://github.com/INFOKOM-KI/Wazuh-MCP-Server) : Wazuh MCP Server: AI-Driven SOC Automation
  - [HoneyAI](https://github.com/martidu4/honey-ai) : All-in-one AI honeypot powered by local LLMs
  - [CAIRN](https://github.com/Cisco-Talos/Cognitive-Artifact-Intelligence-Research-Network) : A research toolkit for identifying, attributing, and tracking AI-related artifacts embedded in malware
